Technologies utilisées :

- React.js pour le frontend

- IOTA et Move pour la blockchain 

Objectif du projet :

- Conception et développement de supply chain avec la blockchain IOTA 

Fonctionnalités principales :

- Ajouter les données liées au rôle dans un formulaire
- Visualiser les données à l'intérieur d'une organisation
- Scanner le code QR
